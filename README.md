# ⏰ Digital Clock

A simple and responsive **Digital Clock Web Application** built using **HTML5, CSS3, and JavaScript**.

This project displays the current hours, minutes, and seconds in `HH:MM:SS` format and automatically updates every second using JavaScript's `setInterval()` function.

---

## 📌 Project Overview

The Digital Clock is developed as part of **VEDA Technology – Web Development Track, Task 4**.

The main purpose of this project is to practice:

- JavaScript `Date` objects
- `setInterval()` timers
- DOM manipulation
- Dynamic content updates
- Responsive web design
- Leading zeros for time formatting

---

## ✨ Features

- 🕐 Displays the current time in `HH:MM:SS` format
- 🔄 Automatically updates every second
- 0️⃣ Adds leading zeros to single-digit values
- 📅 Displays the current date
- 📱 Responsive design for mobile and desktop
- 🎨 Clean and modern user interface
- ⚡ Lightweight and fast
- 🌐 Works directly in any modern web browser
